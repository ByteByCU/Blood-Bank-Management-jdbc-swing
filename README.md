# Blood Bank Management System

A Java Swing and JDBC-based Blood Bank Management System using an Oracle database.

## Features

### Login Page
- Admin Login
- Patient Login

### Admin Dashboard
The admin can:
- Add, View, Update and Delete Patients
- Add, View, Update and Delete Donors
- Add, View, Update and Delete Blood Requests
- Add, View, Update and Delete Blood Inventory

### Patient Dashboard
The patient can:
- Request Blood
- View My Requests

## Technologies Used

- Java
- Java Swing
- JDBC
- Oracle Database

## Project Modules

- Login Page
- Admin Dashboard
- Patient Dashboard
- Patient Management
- Donor Management
- Blood Request Management
- Blood Inventory Management

## Database

The project uses an Oracle database connected through JDBC.
